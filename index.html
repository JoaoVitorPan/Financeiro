📖 Guia de Configuração

1️⃣

Criar Planilha

Acesse sheets.google.com, crie uma planilha e renomeie para "Controle Financeiro".

2️⃣

Abrir Apps Script

Na planilha: Extensões → Apps Script. Apague o código padrão e cole o código fornecido.

3️⃣

Publicar como Web App

Implantar → Nova implantação → Aplicativo da Web. Acesso: Qualquer pessoa.

4️⃣

Colar a URL aqui

Copie a URL gerada (termina em /exec) e cole em ⚙️ Configurar planilha.
